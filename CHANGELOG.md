# Changelog

## 1.7.0 - 2026-11-26

- Add Remote desktops: one-click Remote Desktop sessions with the account saved in the user's Windows credential store, re-enterable at any time

## 1.6.0 - 2026-11-26

- Upload files to a shared folder, with progress, replace confirmation and a per-folder on/off

## 1.5.0 - 2026-11-26

- Reorder the columns of a result by dragging their headers, saved with the panel

## 1.4.2 - 2026-11-26

- Remove the move arrows from panel details: panels are reordered by dragging their handle

## 1.4.1 - 2026-11-26

- Tint folders in shared folders, add Up, a .. row and a clearer breadcrumb to go back, and list Shared folders after Workspaces

## 1.4.0 - 2026-11-26

- Add saved substring filters to shared folders, ignoring case and accents, and make the dialog hints read as examples

## 1.3.0 - 2026-11-26

- Add Shared folders: list and download the files of a network folder with a saved, encrypted account

## 1.2.1 - 2026-11-26

- Shorten the panel refresh label to Refresh

## 1.2.0 - 2026-11-26

- Encrypt the Oracle passwords and the https private keys in the database with Windows DPAPI

## 1.1.2 - 2026-11-26

- Remove the Visible rows text box: a panel is resized with the bar at its bottom edge, and new panels keep the default from Settings

## 1.1.1 - 2026-11-24

- Resize a panel with the mouse by dragging the bar at its bottom edge, in whole rows

## 1.1.0 - 2026-11-24

- Add DBA features: SYSDBA connections with colours, DBA panel templates, a sessions panel with a confirmed Kill button, execution plans, result tools and a connection health page

## 1.0.0 - 2026-11-24

- First release
